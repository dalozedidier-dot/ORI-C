# Actions externes obligatoires

Ces actions ne peuvent pas être déclarées accomplies par le seul dossier local.

| Action | Preuve requise | Statut |
|---|---|---|
| Préenregistrement public ORIC-ABX-001 | URL horodatée, version et SHA-256 | non réalisé |
| Données volumineuses OSF/Zenodo | DOI, licence, manifeste et empreintes | non réalisé pour le paquet ORI-C |
| Réplication positive indépendante | rapport signé, code et données d'une équipe sans lien avec l'ajustement | non réalisé |
| Réplication négative indépendante | mêmes exigences | non réalisé |
| Table de correspondance Windels | clé population reliant trajectoire et phénotype futur | demandée/non obtenue |

Avant dépôt public, le formulaire doit contenir l'hypothèse, les exclusions, partitions, témoins, budgets, métrique, seuil, analyses secondaires, traitement des données manquantes, arrêt et règle de verdict. Le SHA-256 du protocole local doit être publié avec l'enregistrement.
