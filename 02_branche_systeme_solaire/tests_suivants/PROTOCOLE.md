# Tests suivants du Système solaire

`Pacc` est mesuré par interventions réelles dans le modèle N-corps, et non par simple connectivité. Une intervention est accessible lorsqu'elle produit un effet supérieur au bruit sur plusieurs métriques orbitales.

`WP-C2b` remplace l'appariement global défectueux par une calibration séparée selon le régime climatique. Le fichier gelé définit le jeu de validation futur, les seuils et les causes d'échec. Il ne requalifie pas rétrospectivement WP-C2.
