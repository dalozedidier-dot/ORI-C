# Provenance des séries La2010

Ces fichiers sont les séries officielles d’excentricité terrestre publiées par
l’Institut de mécanique céleste et de calcul des éphémérides. Ils n’ont subi
aucune transformation dans le dossier `data/reference/la2010`.

Source :

- https://ssp.imcce.fr/insola/earth/online/earth/La2010/
- https://ssp.imcce.fr/insola/earth/online/earth/La2010/index.html

Référence scientifique :

J. Laskar, A. Fienga, M. Gastineau et H. Manche, « La2010: a new orbital
solution for the long-term motion of the Earth », Astronomy & Astrophysics 532,
A89, 2011. https://arxiv.org/abs/1103.1084

Format indiqué par l’IMCCE :

- colonne 1 : temps depuis J2000 en milliers d’années
- colonne 2 : excentricité terrestre
- suffixe `ecc3L` : pas de 1 000 ans
- suffixe `ecc3` : pas de 5 000 ans
