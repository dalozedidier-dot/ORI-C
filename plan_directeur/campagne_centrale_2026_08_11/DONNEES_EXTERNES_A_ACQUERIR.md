# Données externes à acquérir

Ce registre distingue les liens réellement vérifiés des données qui n'existent pas encore sous une forme exploitable. Un téléchargement ne vaut jamais admission confirmatoire : chaque jeu doit encore satisfaire l'appariement `histoire → trace → persistance → réponse → ablation`.

La liste structurée, les liens directs, la taille connue et le verrou visé sont dans `DONNEES_EXTERNES_A_ACQUERIR.json`.

## Intervention humaine indispensable

- **Compartiments prébiotiques parent-descendant** : aucun dépôt empirique apparié vérifié. Il faut produire l'expérience ou obtenir les données directement des auteurs.
- **PALEO-HISTORY-02** : les séries sont disponibles, mais pas les distributions chronologiques ponctuelles publiées et le contrôle négatif réel préenregistré requis.
- **Prédictions prospectives** : les quatre prédictions sont gelées localement, sans donnée ouverte. Une inscription publique sur [OSF Registries](https://osf.io/registries) doit être faite avant toute acquisition réservée pour constituer une véritable préinscription.
- **Données volumineuses SEM/TEM** : elles ne sont volontairement pas téléchargées dans le dépôt. Leur volume dépasse plusieurs gigaoctets et leur utilité pour la chaîne complète doit être établie avant acquisition.

Les DOI payants ou nécessitant une session sont fournis directement afin que le propriétaire du dépôt puisse les ouvrir avec ses droits institutionnels.
