# PRED-VIVANT-HISTOIRE-001 — voie de réplication par nouvelles MIC

La voie prioritaire n'est plus « attendre qu'un dataset parfait soit publié ». Elle consiste à **produire une nouvelle variable cible** sur des histoires biologiques déjà archivées.

Le LTEE conserve des populations viables à intervalles réguliers. L'histoire de ces lignées existe donc déjà matériellement, mais de nouvelles mesures de susceptibilité peuvent encore être produites après préenregistrement.

## Design cible

1. choisir, uniquement sur métadonnées, plusieurs populations/timepoints LTEE non utilisés dans le jeu D'Onofrio ;
2. faire confirmer par une équipe indépendante que les MIC exactes ciblées n'ont pas encore été produites/ouvertes pour ces échantillons dans le cadre retenu ;
3. préenregistrer `PRED-VIVANT-HISTOIRE-001` et l'analyse avant toute nouvelle MIC ;
4. mesurer ampicilline, érythromycine, tétracycline et tobramycine sous protocole standardisé ;
5. geler/hash la table brute avant décodage ORI-C ;
6. appliquer sans déplacement de seuil : gain RMSE ≥5 %, bootstrap >0, permutation p≤0,05.

## Pourquoi c'est réellement prospectif

L'histoire est ancienne, mais **la variable prédite n'existe pas encore au moment du gel**. C'est l'ordre temporel de la prédiction et de la mesure cible qui compte. Un dataset déjà publié ou des MIC déjà ouvertes restent interdits.
