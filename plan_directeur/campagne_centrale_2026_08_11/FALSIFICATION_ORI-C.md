# Falsification d'ORI-C

ORI-C est affaibli si, sur un benchmark préenregistré de systèmes indépendants :

1. l'histoire n'apporte aucune information conditionnelle sur le futur après
   contrôle de l'état présent ;
2. les modèles état-seul égalent systématiquement les modèles historiques à
   complexité et validation identiques ;
3. l'ablation d'une trace candidate ne réduit jamais la différence de réponse ;
4. aucune définition de `P_acc` ne reste applicable dans au moins deux branches ;
5. les relations candidates `Δm→ΔP_acc` et `tau_m/tau_T→force historique` ne
   se répliquent pas hors échantillon ;
6. les prédictions prospectives gelées restent au niveau des modèles nuls.

Un résultat négatif local limite le domaine de validité ; une accumulation de
résultats négatifs indépendants sur ces six tests affaiblit le cadre général.
Aucun critère ne peut être modifié après ouverture des données réservées.
