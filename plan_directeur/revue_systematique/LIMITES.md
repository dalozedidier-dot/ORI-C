# Limites de la version 0.1

- Le corpus contient **336** entrées, mais seules les entrées de niveau A ont reçu une vérification titre/résumé dans cette campagne.
- Les entrées B possèdent un identifiant stable ou proviennent d’une citation ORI-C, avec métadonnées parfois incomplètes.
- Les entrées C sont des candidats bibliographiques à nettoyer avant usage dans un article.
- La couverture est plus forte pour le Système solaire et le climat, car le dossier ORI-C contient déjà une bibliographie développée dans ces domaines.
- arXiv ne couvre pas uniformément la géochimie, la microbiologie expérimentale et la chimie prébiotique. Les dépôts complémentaires sont obligatoires.
- Les liens de code et de données doivent être archivés avec version, licence, date d’accès et empreinte avant exécution confirmatoire.
- Aucune correspondance automatique publication → hypothèse ne vaut évaluation scientifique. La matrice sert au triage.
