# Classement des tests réalisables

Le classement privilégie le pouvoir discriminant, les données déjà disponibles et la capacité à produire un verdict hors échantillon.

## 1. Antibiotiques : valeur prédictive de l’histoire
- Hypothèses : H-V-002
- Données : Données ORI-C cycles/mesures + CARD/BV-BRC
- Design : Lignées masquées; même MIC finale; témoins sans histoire, cumul, Markov, physiologie et complexité égale
- Critère : gain OOS avec IC excluant 0
- Horizon : immédiat

## 2. Dimensions matière : recodage indépendant
- Hypothèses : H-S-002;H-M-001
- Données : 40 transitions + sources
- Design : ≥3 codeurs aveugles; retirer le régime et les noms de domaine
- Critère : accord + information conditionnelle > 0
- Horizon : 1–2 mois

## 3. Carte temporelle vs chronologie
- Hypothèses : H-S-004;H-M-001
- Données : 40 transitions/47 relations datées
- Design : réseau temporel/higher-order vs chronologie seule
- Critère : AUC OOS supérieure et stable
- Horizon : immédiat

## 4. Pacc empirique commun
- Hypothèses : H-T-001
- Données : chemostat + antibiotiques
- Design : même définition T,C,ε et même procédure
- Critère : mesure non redéfinie dans 2 branches
- Horizon : 1–2 mois

## 5. Émergence causale des niveaux ORI-C
- Hypothèses : H-S-002;H-M-001
- Données : bancs synthétiques et chemostat
- Design : micro vs macro ORI-C sous interventions
- Critère : EI macro > micro avec validation OOS
- Horizon : immédiat

## 6. Astronomie reproductible multi-plateforme
- Hypothèses : H-A-001
- Données : Horizons, La2010
- Design : Lune, J2, marées; 3 OS/2 architectures
- Critère : critères gelés + concordance
- Horizon : 1 mois

## 7. Exoplanètes : bassin et persistance
- Hypothèses : H-C-011;H-C-012;H-C-013;H-C-016
- Données : grilles GCM publiées + NASA Archive
- Design : hot/cold starts; mécanism-denial; palier > toutes constantes
- Critère : écart matériel durable et contrôle apparié
- Horizon : 2–4 mois

## 8. Climat : famille à retard/bistable
- Hypothèses : H-C-004;H-C-005;H-C-014;H-C-015;H-C-017
- Données : LR04 + La2004/La2010
- Design : M1P + persistance + DDE + state-space; rolling OOS
- Critère : 100 ka correcte, RMSE gagnante, identifiable
- Horizon : 1–3 mois

## 9. Climat : réplication multi-archives
- Hypothèses : H-C-004;H-C-006
- Données : LR04 + autres stacks/proxys
- Design : préenregistrement unique; validation archive laissée de côté
- Critère : gain cohérent inter-archives
- Horizon : 2 mois

## 10. Chaîne ORI-C par découverte causale
- Hypothèses : H-T-001
- Données : données antibiotiques et chemostat
- Design : reconstruire arêtes sans les imposer puis interventions
- Critère : arêtes stables et prédictives
- Horizon : 1–2 mois

## 11. Mémoire : taxonomie relaxation/hystérésis/encodage
- Hypothèses : H-C-007;H-V-002
- Données : séries de modèles et bactéries
- Design : temps de relaxation + boucle aller/retour + rappel spécifique
- Critère : classement D-H-L reproductible
- Horizon : 1–2 mois

## 12. Filtrages planétaires prédictifs
- Hypothèses : H-M-001
- Données : EarthChem/GEOROC/météorites
- Design : corps laissés de côté; composition statique vs histoire
- Critère : gain OOS de l’histoire
- Horizon : 3–6 mois

## 13. Compression explicative du Codebook
- Hypothèses : H-T-002
- Données : résultats de toutes branches
- Design : modèle avec/sans chaque concept
- Critère : gain net de description/prédiction
- Horizon : après tests 1–5

## 14. Banc protocellulaire de réplication
- Hypothèses : H-V-001
- Données : protocole 2026 + chimie contrôlée
- Design : ablations et lignées, pas seulement morphologie
- Critère : 6/6 + avantage fonctionnel + réplication
- Horizon : partenariat labo

## 15. Nulls spectraux à puissance suffisante
- Hypothèses : H-C-009
- Données : LR04
- Design : ≥1000 surrogates, blocs et corrections multiples
- Critère : p gelée + puissance déclarée
- Horizon : immédiat

## 16. Identifiabilité climatique globale
- Hypothèses : H-C-015
- Données : LR04
- Design : graines, fenêtres, profils, postérieurs
- Critère : paramètres stables ou modèle rejeté
- Horizon : immédiat

## 17. Edge states et observables climatiques
- Hypothèses : H-C-013;H-C-016
- Données : modèles bistables
- Design : identifier l’état bord et variables EWS
- Critère : frontière reproductible
- Horizon : 2 mois

## 18. Robustesse des liens planétaires
- Hypothèses : H-M-001
- Données : données isotopiques et thermiques
- Design : leave-one-family-out
- Critère : prédiction calibrée
- Horizon : 3 mois

## 19. Test d’invariance interbranche
- Hypothèses : H-T-001
- Données : deux jeux choisis
- Design : même métrique et seuil
- Critère : relation stable OOD
- Horizon : après Pacc

## 20. Réplication externe du test interventionnel
- Hypothèses : H-S-001;H-S-003
- Données : script + protocole
- Design : réimplémentation aveugle
- Critère : 11/11 + cas non monotones
- Horizon : immédiat
