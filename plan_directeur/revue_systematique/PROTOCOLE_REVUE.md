# Protocole de revue

## Question

Quelles publications, données, méthodes et implémentations peuvent :

1. opérationnaliser les notions ORI-C ;
2. fournir un test falsifiable ;
3. confirmer ou contredire une hypothèse enregistrée ;
4. offrir un témoin concurrent de complexité égale ;
5. permettre une réplication indépendante ?

## Sources

Le noyau de cette version combine :

- références déjà citées dans le états antérieurs du dossier ORI-C ;
- balayage ciblé d'arXiv jusqu'au 1er août 2026 ;
- dépôts complémentaires nécessaires : EarthArXiv, bioRxiv, ChemRxiv, Europe PMC et dépôts de données disciplinaires.

## Inclusion

Une publication est retenue lorsqu'elle apporte au moins un élément : variable mesurable, mécanisme, intervention, donnée, code, méthode, modèle concurrent, résultat négatif ou protocole de réplication.

## Exclusion

Sont exclus de la synthèse positive : textes purement analogiques, absence de variable mesurable, absence de système défini, revendications de finalité cosmique, succès uniquement en ajustement interne sans témoin, et résultats synthétiques présentés comme preuves empiriques.

## Dédoublonnage

Ordre des clés : DOI, identifiant arXiv, URL stable, titre normalisé. La version A remplace B ou C lorsqu'un même enregistrement existe à plusieurs niveaux.

## Limites

Cette est une carte de travail large. Les entrées B et C exigent encore une complétion bibliographique et un dépouillement du texte intégral. Les décisions confirmatoires doivent utiliser uniquement des entrées A après vérification du papier, des données et du code.
