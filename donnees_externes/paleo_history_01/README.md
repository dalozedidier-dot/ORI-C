# Sources de PALEO-HISTORY-01

Sources primaires ou dépôts officiels acquis le 11 août 2026 : Prob-stack
(pile benthique indépendante), niveau marin NOAA, poussières EPICA/PANGAEA et
solution orbitale La2004/IMCCE. `SOURCES.json` conserve les URL, références et
empreintes des téléchargements originaux.

Ces fichiers complètent les cinq sources déjà présentes dans
`donnees_reelles_2026_08_07/paleoclimat_long` et `orbit91`. Leur présence ne
vaut pas admission : le protocole exige encore une table normalisée et des
incertitudes chronologiques validées ligne par ligne.
