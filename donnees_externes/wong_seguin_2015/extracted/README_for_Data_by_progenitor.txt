Readme for “Data_by_progenitor.tsv”, associated with Wong and Seguin 2015, “Effects of genotype on rates of substitution during experimental evolution”, Evolution


This file contains phenotypic data, as well as summaries of genotypic data, for the six founding strains. Columns are as follows:

Genotype: Name of founding genotype.

Mutation: Mutation present in founding genotype.

Gene: Gene in which mutation is located.

S1-S5: Measurements of selection coefficient from competitive assays; up to 5 replicates.

Average_w: average fitness from S1-S5

Mean_substitutions: Mean number of substitutions per population accrued over the selection experiment.

Sdev_substitutions: standard deviation in number of substitutions

n: number of populations surviving to the end of the selection experiment.

Total_subs: total number of substitutions across all populations for a given founding genotype.

Mean_Nc: average census population size for fluctuation assays.

Nc_SE: Standard error in census population size.

M_per_107: inferred mutation rate per 10^7 cells

Upper, lower: upper and lower confidence intervals on mutation rate per 10^7 cells

m_total_cip: inferred mutation rate per population

Cultures: cultures with detectable mutants in fluctuation assay

Ds_total_of_medians_f: from downsampling experiment, median number of substitutions across populations for a given genotypes

Ds_total_of_medians_p: from downsampling experiment, median number of polymorphisms across populations for a given genotypes

Response: mean response to selection
