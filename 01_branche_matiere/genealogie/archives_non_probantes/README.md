# Résultat informationnel retiré des preuves actives

Le fichier conservé dans ce dossier annonce un gain conditionnel calculé sur des champs textuels presque uniques. Il peut mémoriser les lignes au lieu de mesurer une relation généralisable. Aucun script reproductible ne permettait de reconstruire ce résultat dans la livraison reçue. Il est conservé uniquement pour la traçabilité et ne doit pas être cité comme preuve scientifique.

Toute nouvelle mesure devra utiliser des catégories définies indépendamment de la cible, une validation hors échantillon et une comparaison par permutations.
