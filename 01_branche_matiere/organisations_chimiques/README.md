# Pont Chemical Organization Theory

Le module `cot.py` implémente un test minimal de clôture et d'auto-maintenance via faisabilité de flux stœchiométriques. L'hypergraphe ORI-C courant ne contient pas de matrice stœchiométrique suffisante : `resultats/DIAGNOSTIC.json` reste donc **non évaluable** plutôt que de confondre atteignabilité documentaire et organisation chimique.
