# Généalogie globale ORI-C

Ce dossier contient l’arbre reliant les transformations matérielles, planétaires et biologiques. Le CSV est la source d’autorité. Le script recalcule la clôture et le rapport JSON.

La clôture signifie que chaque parent matériel est produit auparavant ou déclaré comme entrée externe. Elle établit la cohérence interne du graphe, sans démontrer à elle seule l’exactitude historique ni la suffisance causale de chaque transition.

Les niveaux de preuve sont séparés en quatre axes. Leur premier remplissage reste préliminaire et doit faire l’objet d’une revue bibliographique indépendante transition par transition.

Commande : `python arbre_genealogique.py`
