C. THÉORÈMES
------------------------------------------------------------------------
  C1 : Équilibre de lavage E0 = (S_in, 0), toujours présent. Valeurs propres -D et mu(S_in) - m.
  C2 : Équilibre intérieur E* = (K_s m/(mu_max - m), D(S_in - S*)/m), existant et positif si et seulement si m < mu(S_in).
  C3 : dP*/dm = -D [K_s m^2 + S_in (m - mu_max)^2] / [m^2 (mu_max - m)^2] < 0 pour tout m > 0, m != mu_max. La décroissance est donc stricte sur tout le domaine admissible, sans condition de viabilité.
  C4 : trace J(E*) = -D [K_s m^2 + S_in (m - mu_max)^2] / (K_s m mu_max) < 0 ; det J(E*) > 0 dès que E* est intérieur. E* est donc toujours localement asymptotiquement stable.
  C5 : Avec B = 1/P, div(B f) = -D/P - mu'(S) < 0 sur P > 0 : critère de Dulac satisfait, aucune orbite périodique dans le quadrant ouvert.
  C6 : pour toute mu strictement croissante et dérivable, dP*/dm < 0
       dès que l'équilibre intérieur existe.
