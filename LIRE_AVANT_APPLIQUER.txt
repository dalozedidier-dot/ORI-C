ORI-C — correction barrière scientifique avec reconstruction SHA automatique

Ne copie pas directement le dossier payload dans GitHub.
Lance le script depuis ce paquet :

  python APPLIQUER_CORRECTION.py --repo "CHEMIN_VERS_LA_RACINE_ORI-C"

Option de validation plus complète :

  python APPLIQUER_CORRECTION.py --repo "CHEMIN_VERS_LA_RACINE_ORI-C" --full-validation

Le script :
1. vérifie que les fichiers locaux à remplacer sont exactement ceux de la base GitHub auditée ;
2. vérifie tous les SHA-256 du payload ;
3. crée une sauvegarde hors du dépôt ;
4. copie la correction ;
5. exécute IMMEDIATEMENT `python build_manifest.py build` ;
6. vérifie `MANIFEST.sha256` et `MANIFEST.sha256.json` ;
7. exécute les validateurs d'intégrité et de barrière scientifique.

Les deux manifestes sont volontairement reconstruits SUR LE DÉPÔT RÉEL APRÈS application :
c'est plus sûr qu'un MANIFEST pré-calculé, qui deviendrait faux dès qu'un autre fichier du dépôt change.

En cas d'échec après modification, le script restaure automatiquement les fichiers précédents et les anciens manifestes.
