# Nader — caractérisation physique AVT

Le classeur réel est extrait sans utiliser la feuille théorique `FigS6` comme
donnée empirique. Une table sans perte recense toutes les cellules numériques
des feuilles expérimentales; des tables propres isolent les chromatogrammes,
les blocs explicitement associés à la solution 2:1 acide décanoïque:décanol
et les tailles individuelles publiées.

Cette étude calibre les plages physiques du système. Elle ne remplace jamais
l'expérience prospective `control / do(m) / sham` de VES-PACC-INT-01.
