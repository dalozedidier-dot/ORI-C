# Données réelles du programme prébiotique

Deux catégories sont séparées.

## Trajectoires de populations

`trajectoires_population/papastavrou_rna_huit_cycles.csv` contient des fréquences publiées de séquences d’ARN catalytique pour deux branches expérimentales suivies pendant huit cycles. Le grain est `branche-cycle-séquence`. Ces données décrivent une dynamique réelle de composition.

## Lignées parent-descendant

Aucune table expérimentale de compartiments parents et descendants n’est intégrée. Une table recevable doit suivre `schema_lignees/gabarit/lignees.csv`, ne pas porter le marqueur `GABARIT_SYNTHETIQUE`, relier les compartiments sur plusieurs cycles et documenter les témoins.

Une trajectoire de fréquences ne doit jamais être reclassée comme lignée héréditaire.
