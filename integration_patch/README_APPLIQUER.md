# Intégration ORI-C

Cet arbre est un overlay scientifique, pas un dépôt complet autonome.

Base attendue : `ORI-C-main-20260815T193827Z-1-001.zip`, la base complète explicitement utilisée dans la conversation précédente.

Les ajouts sont placés dans les chemins ORI-C correspondants. Les manifestes racine ne sont volontairement pas fournis comme nouveaux manifestes canoniques, puisque la base exacte n'est plus accessible dans la session actuelle. Après application sur la base exacte, il faut utiliser l'outil de manifeste du dépôt et relancer ses validations avant toute publication.

Ne pas appliquer cet overlay à une autre base en supposant qu'elle est équivalente.
