# Statut de licence

Le fichier `LICENSE` fixe provisoirement un statut clair : tous droits réservés
pour les contenus originaux qui ne possèdent pas déjà leur propre licence.
Aucune licence ouverte générale n'est encore accordée.

Avant une publication destinée à la réutilisation, l'auteur doit choisir
explicitement une politique séparant au minimum :

- le code original ;
- les textes et figures ;
- les données produites par ORI-C ;
- les données et composants tiers ;
- les sous-projets qui possèdent déjà leur propre licence.

Cette décision est volontairement laissée à l'auteur. Elle ne peut pas être
prise automatiquement lors d'une correction technique.
