# Comparaison formelle avec Assembly Theory

Le pont implémente l'équation d'assemblage publiée à partir de l'indice d'assemblage et du nombre de copies, ainsi qu'un comparateur apparié avec une profondeur ORI-C. Le dépôt ne possède pas encore ces observables sur les **mêmes objets** ; la comparaison courante est donc fail-closed et ne renomme pas la profondeur ORI-C en assembly index.
