Résultat de modèle pré-calculé

Scénarios N-corps Jupiter / Saturne

Les six scénarios sont lus dans la table de contre-factuels existante. Ils peuvent être comparés, mais pas interpolés arbitrairement.

Pourquoi il n'y a pas de curseur continu

Un curseur donnant n'importe quelle masse ou position de planète demanderait de relancer réellement l'intégration. Interpoler entre six sorties donnerait une impression de précision non calculée.

Cette page reste donc un explorateur de scénarios calculés. Le dépôt conserve l'intégrateur complet pour les nouvelles expériences numériques.

Modèle jouet pédagogique

Bac à sable : Histoire → Architecture → Possibles

Ce module n'utilise aucune donnée ORI-C et ne compte dans aucun résultat. Il sert uniquement à rendre la logique du cadre visible.

L'ablation annule l'effet de l'histoire sur les rigidités internes. Le même forçage final est alors appliqué à l'architecture réinitialisée.

Statut : démonstration pédagogique uniquement. Elle montre qu'une architecture dépendante de l'histoire peut modifier une réponse future dans un modèle construit pour cela ; elle ne constitue pas une validation empirique d'ORI-C.
