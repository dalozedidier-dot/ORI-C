Contrôle global

Vérifier le dossier en une commande

Le script vérifie chaque empreinte, détecte les fichiers absents ou non listés et contrôle la présence des éléments canoniques.

git clone https://github.com/dalozedidier-dot/ORI-C.git
cd ORI-C
python verifier_dossier.py
python scripts/valider_tout.py
