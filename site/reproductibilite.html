Vérifier le dépôt et le manifeste

Le manifeste recense tous les fichiers suivis, y compris les objets Git LFS selon leur OID et leur taille déclarée.

La campagne cumulative compare les structures JSON exactement et les valeurs flottantes avec une tolérance relative de 10−8 et une tolérance absolue de 10−10.

python build_manifest.py verify
python verifier_dossier.py --allow-lfs-pointers

Le premier contrôle compare la liste, la taille et l’empreinte de chaque fichier. Le second vérifie aussi la structure du dossier et les objets LFS.
