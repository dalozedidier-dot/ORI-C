# Documents canoniques et alias de livraison

Le document scientifique canonique se trouve dans :

- `documentation/dossier_scientifique/DOSSIER_SCIENTIFIQUE_ORI-C.docx`
- `documentation/dossier_scientifique/DOSSIER_SCIENTIFIQUE_ORI-C.pdf`

Les fichiers racine suivants sont des alias byte-identiques conservés pour un
accès direct et pour la continuité des liens de diffusion :

- `LE_POSSIBLE_A_UNE_HISTOIRE.docx`
- `LE_POSSIBLE_A_UNE_HISTOIRE.pdf`

Toute modification éditoriale doit être faite sur la source canonique, puis
répercutée vers les alias. Les alias ne constituent pas des versions
scientifiques distinctes.
